# How Do You Know: The Game

A party map generator built with SvelteKit. Graph the people at your party and the connections between them. Exports to GraphViz, PNG, and SVG.

Tired of "so what do you do"? Allergic to such and such? Give your guests something to talk about.

## How to play

1. Add names of everyone at your next party.
2. Add connections between names. Favor fun facts that start a story: **"Runner-up to the break room Olympics"** instead of *"Work."*
3. Take it offline. Print the graphs and have your guests fill out missing spaces.

## Development

```
npm install
npm run dev      # start the dev server
npm run check    # sync types + svelte-check
npm run test     # run the Vitest suite
npm run build    # create the static SPA build
npm run preview  # serve the production build
```
